# 🚀 Quick Start Guide - Unemployment Analysis

## In 5 Minutes ⏱️

### 1️⃣ Download Dataset
```bash
# Download from Kaggle
# Search: "Unemployment in India"
# File: Unemployment_in_India.csv
# Save to: Your working directory
```

### 2️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```

### 3️⃣ Run Jupyter Notebook
```bash
jupyter notebook unemployment_analysis.ipynb
```

### 4️⃣ Run Streamlit App
```bash
streamlit run streamlit_app.py
```

### 5️⃣ Explore!
- Open your browser
- Interact with visualizations
- Download data
- Analyze trends

## 🔧 Common Commands

```bash
# Install everything
pip install -r requirements.txt

# Update packages
pip install --upgrade pandas numpy matplotlib streamlit

# Run Jupyter
jupyter notebook

# Run Streamlit
streamlit run streamlit_app.py

# Clear Streamlit cache
streamlit cache clear

# Run Python script directly
python unemployment_analysis.py

# Create virtual environment (recommended)
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate      # Windows
```

## ❓ Troubleshooting

| Problem | Solution |
|---------|----------|
| "No module named pandas" | `pip install pandas` |
| CSV file not found | Place file in same directory |
| Streamlit won't start | `pip install --upgrade streamlit` |
| Jupyter won't launch | `pip install jupyter --upgrade` |
| Port already in use | `streamlit run streamlit_app.py --server.port 8502` |
