# 📊 Unemployment Analysis with Python

## 🎯 Objective

To perform Exploratory Data Analysis (EDA) on unemployment data in India and identify regional patterns, monthly trends, relationships between employment indicators, and changes observed during the COVID-19 period.

## 🔧 Steps Performed

1. 📥 Loaded the "Unemployment in India" dataset.
2. 🔍 Inspected the dataset structure, shape, data types, and missing values.
3. 🧹 Cleaned and prepared the data for analysis.
4. 📍 Analysed region-wise average unemployment rates.
5. 📅 Studied monthly unemployment trends.
6. 📈 Compared unemployment trends across selected regions.
7. 🏆 Identified the top 10 regions with the highest average unemployment rates.
8. 🔥 Created a correlation heatmap for unemployment rate, employment rate, and labour participation rate.
9. 🦠 Compared employment indicators between the pre-COVID and COVID periods.
10. 📊 Created visualizations and recorded observations for the analysis.
11. 🌐 Developed an interactive Streamlit dashboard for exploring the results.

## 🛠️ Tools & Technologies

- 🐍 Python
- 🐼 Pandas
- 🔢 NumPy
- 📈 Matplotlib
- 🎨 Seaborn
- 📊 Plotly
- 🌐 Streamlit
- 📓 Jupyter Notebook

## 📊 Outcome

The analysis provides insights into regional and temporal unemployment patterns in India and compares key employment indicators between the pre-COVID and COVID periods.
